## D1 项目名：韭见 JiuJian ✅
显示名「韭见」，slug/包名 `jiujian`。韭菜(散户)+洞见 → "让韭菜有洞见"。社区原生、有记忆点。

## D2 定位：个人非商业 · 更丰富使用自己的 Claude Code ✅
- **决定**：**不商业**。目标是更丰富地使用作者自己已付费的 Claude Code 订阅；做一个个人股票分析利器。
- **卖点重述**：原"蹭订阅冗余算力 = 免费"在 6-15 后失效（见 D9 风险 2）。新定位不依赖"免费"——**把订阅自带的月度 Agent SDK 额度（Pro $20/Max5x $100/Max20x $200）变现成股票分析能力**，正是"更丰富地使用我的 Claude Code"。
- **影响**：非商业 + 自用大幅消解 ToS 风险（见 D9）；分发范围细节见 D10。

## D3 AI 接入：无头 `claude -p` + stock-sdk MCP ✅
- Main 进程 `spawn(claude -p ... --output-format stream-json --strict-mcp-config --mcp-config <cfg>)`，挂 stock-sdk-mcp，Claude 自主调 ~70 个工具拉数据+分析，readline 逐行 parse 流式回渲染层。
- 注：Agent SDK 不支持订阅 OAuth，订阅路径只能走 `claude -p` 外壳。

## D4 数据源：`stock-sdk` / `stock-sdk-mcp` ✅
- 核心 `stock-sdk@1.10.0`（零依赖、Node≥18、无 API key、腾讯 qt.gtimg.cn）；MCP 是**独立包** `stock-sdk-mcp@0.2.1`（bin `stock-mcp`，stdio，~70 工具）。
- **双路用法（拍板，原开放决策 #4）**：AI 分析链路走 claude + `stock-sdk-mcp`（MCP）；**K线图表走 main 进程直接 `import` 核心 `stock-sdk`**（快/与 claude 运行解耦/不烧 Agent SDK 额度）。两个包都装为直接依赖。
- 代价：公开端点，几十秒~分钟延迟 → 能分析，不能做交易信号；需"数据截至时间 + 非实时"提示。

## D9 承重假设可行性 🟢（个人非商业用 GREEN）
- **技术 GREEN**：本机已验证 claude 2.1.156 登录订阅 OAuth + stock-sdk-mcp 可挂载，无头闭环可跑。
- **ToS（原风险 1）→ 消解**：自用 = "ordinary, individual usage of your own Claude Code"，正是官方允许；非商业不触发"第三方商业路由"禁令。残余取决于分发范围（D10）。
- **配额（原风险 2）→ 非风险**：6-15 后 `claude -p` 从独立月度 Agent SDK 额度按 API 价扣费、不滚存；对自用者，这笔额度本就是给程序化用途的，拿来跑分析正是"更丰富使用"。仍建议做成本/额度遥测 + 402 友好处理。
- **裁决**：个人非商业场景 GREEN。（若未来扩到公开/商业，回退 YELLOW 并需 Anthropic 书面澄清。）

## D10 分发范围 + 鉴权策略 ✅
- **决定**：**先自用，预留分享**。当前只服务作者自己；架构上把 claude 探测/登录/鉴权抽象成**可插拔 provider 接口**，未来开源分享时不重构。
- **鉴权**：**仅实现订阅 CLI provider**（本机 `claude -p` OAuth）。不实现 API key（YAGNI），但接口留着，未来加 API key/Agent SDK provider 直接补一个实现即可。
- **架构落点**：`AuthProvider` 接口 + 唯一实现 `SubscriptionCliProvider`；`path-resolver`（fix-path + which/alias 解析 + 用户覆盖）+ `claude auth status --json` 探测归此层。
