# 韭见 JiuJian

> 让韭菜有洞见 —— 一个复用你自己 Claude Code 订阅冗余算力的 AI 股票分析桌面应用。

## 这是什么

**韭见** 是一个 Electron 桌面应用。它把 [`stock-sdk`](https://github.com/chengzuopeng/stock-sdk) 的实时行情数据，交给你**本机已登录的 Claude Code 订阅**做 AI 分析——应用本身不消耗任何 API 费用，跑的是你已经付费的订阅里那部分"冗余算力"。

## 核心理念：BYO 订阅（自带订阅）

- 应用分发给他人使用，但**不打包作者的订阅**。
- 每个用户自带 Claude Code (Max/Pro) 订阅并在本机登录。
- 应用提供：行情数据 + 交互界面 + 编排逻辑；用户的订阅提供：AI 算力。
- 卖点：把你早已付费、却大量闲置的订阅额度，变现成股票分析能力。

## 技术栈

| 维度 | 选型 |

| 数据源 | `stock-sdk`（A股/港股/美股/基金ETF，零依赖、无需 API key） |
| AI 引擎 | 无头 `claude -p` + stock-sdk MCP（待地基调研最终确认） |
